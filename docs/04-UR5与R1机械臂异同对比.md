# UR5 与宇树 R1 机械臂 · 异同对比

> **本文档回答一个问题：换一台机械臂，我们要改什么、不用改什么？**
>
> 结论先给：**三角函数不用换，换的只是"角度怎么串起来"。**

本文所有数字都由 `armblocks` 直接从两台机器的官方 URDF 实测得出，
可用 `python demos/demo_compare_arms.py` 复现。

---

## 一、一句话定位

| | **UR5**（主力机） | **宇树 R1 机械臂**（对照机） |
|---|---|---|
| 出身 | 丹麦 Universal Robots，经典工业协作臂 | 杭州宇树科技，人形机器人 R1 的机械臂 |
| 自由度 | **6** | **7** |
| 结构 | 标准 **DH** 构型，6 个关节**全部绕自身 z 轴** | 关节轴 **z/x/y 混合**，非标准 DH |
| 教学角色 | 主线：推导最"干净"，把三角函数讲透 | 对照：多一个自由度，看冗余带来什么 |

## 二、实测参数对照

| 项目 | UR5 | 宇树 R1 |
|---|---|---|
| 自由度 | 6 | 7 |
| 关节轴排布 | `z z z z z z` | `-z x y x y -x -z` |
| 固定节（不占自由度） | **3** 个（`base_link_inertia`、`flange`、`tool0`） | 0 个 |
| 末端参考系 | `tool0`（法兰中心） | `Link7` |
| 零位末端位置 | **(0.817, 0.191, −0.005) m** | (0.003, −0.034, 0.193) m |
| 零位末端距底座 | 0.839 m | 0.196 m |
| 末端可达半径范围 | **0.036 – 1.028 m** | 0.013 – 0.542 m |
| 腕部结构 | **非球形**（轴 4 ∥ 轴 6，相距 94.65 mm） | **近似球形**（三轴几乎共点，偏差 5.0 mm） |
| 位置/姿态可解耦 | **不成立** | 近似成立 |
| 冗余度 | 无（6 轴 = 6 自由度） | **有**（7 轴 > 6，无穷多解） |
| IK 策略 | 可解析（但要处理腕部耦合） | 数值解 + 选解准则 |
| 名义负载 / 自重 | 5 kg / 18.4 kg | 2 kg / 5.5 kg |
| 重复定位精度 | ±0.1 mm | — |

### 各关节限位

| # | UR5 关节 | 限位 | R1 关节 | 限位 |
|---|---|---|---|---|
| 1 | `shoulder_pan_joint` | ±360° | `J1` | ±156° |
| 2 | `shoulder_lift_joint` | ±360° | `J2` | 0 … 180° |
| 3 | `elbow_joint` | **±180°** | `J3` | −20 … 200° |
| 4 | `wrist_1_joint` | ±360° | `J4` | −180 … 0° |
| 5 | `wrist_2_joint` | ±360° | `J5` | ±130° |
| 6 | `wrist_3_joint` | ±360° | `J6` | ±30° |
| 7 | — | — | `J7` | ±90° |

> 这组限位是两台机器**性格差异**的直接来源：
> UR5 几乎可以"整圈转"，R1 的每个关节都卡在比较窄的扇区里
> —— 所以 R1 的"多解筛选"比 UR5 更受约束。

## 三、相同点（4 条）

### 1. 都是串联开链，"变换链"思想完全一致

$$
T_{\text{末端}} = T_1(q_1)\cdot T_2(q_2)\cdots T_n(q_n),
\qquad T_i = \underbrace{\text{平移} + \text{固定旋转}}_{\text{关节装在哪、朝哪边}} \cdot \underbrace{R_{\text{轴}}(q_i)}_{\text{这次转了多少}}
$$

两台机器**共用同一份代码**（`armblocks/core/kinematics.py`），换的只是 URDF 文件。

### 2. 都是 6 个有效位姿自由度

空间刚体位姿就是 6 维（3 平移 + 3 旋转）。UR5 用 6 轴正好；R1 用 7 轴**多给了 1 个**。

### 3. 关节变换只用 sin / cos

$$
R_z(\gamma)=\begin{bmatrix}\cos\gamma & -\sin\gamma & 0\\ \sin\gamma & \cos\gamma & 0\\ 0&0&1\end{bmatrix},\quad
R_x(\alpha)=\begin{bmatrix}1&0&0\\0&\cos\alpha&-\sin\alpha\\0&\sin\alpha&\cos\alpha\end{bmatrix},\quad
R_y(\beta)=\begin{bmatrix}\cos\beta&0&\sin\beta\\0&1&0\\-\sin\beta&0&\cos\beta\end{bmatrix}
$$

**没有第三条公式。** 这是本课程的核心论点。

### 4. 姿态都靠最后 3 个关节

|  | 位置（前几轴） | 姿态（腕部） |
|---|---|---|
| UR5 | pan / lift / elbow | wrist_1 / 2 / 3 |
| R1 | J1–J4 | J5 / 6 / 7 |

## 四、不同点（4 条，且都能"用数字说话"）

### 差异 1｜轴排布：全 z vs z/x/y 混合

**UR5**：6 个关节的 URDF 里 `axis` **全都是 `0 0 1`**。
那"倾斜"去哪儿了？——藏进了**关节原点的 `rpy`**：

```xml
<joint name="shoulder_lift_joint" type="revolute">
  <origin xyz="0 0 0" rpy="1.570796327 0 0"/>   <!-- ← 这个 π/2 就是 DH 的 α₁ -->
  <axis xyz="0 0 1"/>
</joint>
```

这正是标准 DH 里那个 **α 角**，物理含义是"上一根轴和这一根轴差了 90°"。

**R1**：`axis` 本身就是 `-z / x / y / x / y / -x / -z`，倾斜直接写在轴向量里。

> **教学含义**：UR5 逼着学生理解"原点 rpy 里那个 π/2 到底在干什么"；
> R1 则更直观——但两者都要用同一套 `Rz · Ry · Rx` 旋转积木。

### 差异 2｜腕部几何：**这是最反直觉、也最重要的一条**

课本常说："六轴臂最后三根轴交于一点（球形手腕），于是位置与姿态可以解耦。"
**真实机型往往不是这样。** 我们直接量：

```
——— UR5 腕部几何 ———
  wrist_1_joint      轴上一点 [0.81725 0.10915 0.08916]
  wrist_2_joint      轴上一点 [0.81725 0.10915 -0.00549]
  wrist_3_joint      轴上一点 [0.81725 0.19145 -0.00549]
  轴间最短距离 wrist_1–wrist_2:   0.000 mm
  轴间最短距离 wrist_1–wrist_3:  94.650 mm  ← 平行!
  轴间最短距离 wrist_2–wrist_3:   0.000 mm
  ⇒ 三轴不共点（最大偏差 47.33 mm）：不是球形手腕
```

**UR5 的轴 4 与轴 6 是平行的、相距 94.65 mm**（正好等于 DH 表里的 `d₅ = 0.09465 m`）。
所以：

| 只转一个腕关节 90° | 末端 tool0 移动 |
|---|---|
| `wrist_1_joint`（轴 4） | **133.9 mm** |
| `wrist_2_joint`（轴 5） | **116.4 mm** |
| `wrist_3_joint`（轴 6） | **0.00 mm** ← 因为 tool0 正好落在这根轴上 |

这被权威文献明确证实：

> *"A peculiarity of the UR5 structure is that it does not have a spherical wrist;
> therefore, there is no point in which the three axes of the wrist joints intersect."*
> — MDPI *Robotics* 12(3):71, 2023

> *"...the non-coincidental arrangement of the final 3 joints, which do not form a
> traditional spherical wrist. Consequently, all six joints contribute independently
> to both translational and rotational motion of the end-effector."*
> — arXiv:2510.19081（针对 UR5e）

**而 R1 反而更接近球形手腕**：三轴几乎交于一点，最大偏差仅 **5.0 mm**：

```
  轴间最短距离 J5–J6:   0.700 mm
  轴间最短距离 J5–J7:   0.000 mm
  轴间最短距离 J6–J7:  10.000 mm
  ⇒ 最大偏差 5.01 mm → 近似球形腕
```

> **教学含义（关键）**：
> "位置用球坐标 + 余弦定理、姿态用欧拉角"这套漂亮分工，
> **在 UR5 上只是近似**。所以课程必须让学生亲手验证这个假设何时失效，
> 并用**数值 IK** 兜底做真值对照 —— 这恰恰是本课程"理论带动实践"最有价值的时刻。

### 差异 3｜自由度：6 轴"够用" vs 7 轴"富余"

| | UR5（6 轴） | R1（7 轴） |
|---|---|---|
| 方程数 | 6 | 6 |
| 未知数 | 6 | 7 |
| 解的个数 | **有限**（最多 8 组：肩×肘×腕各两种） | **无穷多**（1 维解流形） |
| 怎么选 | 从有限解里挑 | 需**选解准则**：离限位最远 / 离当前位形最近 / 关节运动量最小 |

冗余也不是坏事——多出来的自由度能干这些活：
避障、绕开奇异位形、在末端不动时躲开关节限位、省力姿态。

### 差异 4｜IK 策略：解析 vs 数值

| | UR5 | R1 |
|---|---|---|
| 解析解 | 可求（分位置 / 姿态两段推导，但要处理腕部耦合） | 一般不求，太繁琐 |
| 本框架做法 | 数值 IK 做真值，学生练**子问题**（平面 2R、欧拉角） | 同左 + 选解准则 |
| 奇异位形 | 肩奇异 / 肘奇异 / 腕奇异三类 | 更复杂（冗余臂的奇异是高维流形） |

## 五、教学主线里两条机型怎么分工

```
阶段三·升维   M6 球坐标 ── M7 旋转矩阵 ★── M8 三维正运动学
                                                  │
                              用 UR5 搭出完整正解（全绕 z，最好推）
                                                  │
阶段四·三维逆解 M9 位置逆解 ── M10 姿态逆解 ── M11 整合/多解/奇异
                    │              │                 │
            子问题：平面 2R + 球坐标   子问题：欧拉角      数值 IK 兜底
                    │              │                 │
                    └── 反例检查：UR5 不是球形腕！ ──┘
                                                  │
阶段五·综合项目 M12 轨迹 ── M13 综合任务 ── M14 展示答辩
                                                  │
                              对照 R1：多一个自由度会怎样？（选解准则）
```

**一句话总结分工**：

- **UR5 负责"讲清楚"**：结构规整、推导经典、误差可量化；
- **R1 负责"讲复杂"**：同样的框架，加上冗余、窄限位、混合轴 —— 学生立刻体会到
  "真实机器人没有教科书那么乖"。

## 六、代码层面：到底改了哪些行？

这是最能说明"共用"的证据。接入第二台机器，**核心代码零改动**：

| 文件 | 是否改 | 说明 |
|---|---|---|
| `core/transform.py` | 小改 | `axis_rotation` 已支持任意对齐轴；新增 `rpy_to_matrix(..., rot=)` 让原点 rpy 也走学生积木 |
| `core/kinematics.py` | 小改 | `link_frames` 改为沿**完整链条**推进，把固定关节一起算进去 |
| `core/urdf_model.py` | 小改 | 支持链条中的**固定关节**（UR5 的 `base_link → base_link_inertia`） |
| `core/geometry.py` | 新增 | 关节轴直线、轴间距离、球形手腕判定 |
| `blocks/rotations.py` | **不动** | 三块旋转积木同吃两台机器 |
| `blocks/planar.py` / `wrist.py` | **不动** | 平面 2R、欧拉角是通用子问题 |
| `models/ur5/` | 新增 | UR5 的 URDF + 网格 |
| `models/r1_7a/` | 不动 | R1 原样保留 |

```python
# 同一段代码，两台机器
from armblocks import UR5_URDF, R1_URDF, load_model, fk, blocks
import numpy as np

for path in (UR5_URDF, R1_URDF):
    m = load_model(path)
    p, R = fk(m, np.zeros(m.dof), rot=blocks.rotations)   # ← 学生的积木
    print(m.name, m.dof, p)
```

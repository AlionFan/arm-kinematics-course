一、课程定位与设计理念

1.1 一个驱动问题

机械臂只有几个"会转的关节"，它怎么"知道"自己的手在空间的什么地方、朝向哪里？

反过来，我想让它的手精准到达某个位置和姿态，它又该怎么算每个关节要转多少度？

这个"正着算"（正运动学 FK）与"反着算"（逆运动学 IK）的问题，是机器人学的第一道门槛，也恰好是一道纯粹的三角几何题。本课程的全部设计都围绕这句话展开。

1.2 核心理念：三角函数是"空间的语言"

高中课上的三角函数，常被当作"算三角形边角"的解题工具。本课程要传递一个更大的观念：

  • sin、cos 的本质是坐标——单位圆上一个角度 θ，对应的点就是 (cos θ, sin θ)；
  • 一根长度固定、只能绕一端转动的连杆，末端坐标就是 (L·cos θ, L·sin θ)——三角函数就是"角度→位置"的翻译器；
  • 机械臂 = 一串连杆 = 一串三角函数的叠加与复合；
  • 平面上的"长度 + 角度"（极坐标）升维到空间，自然变成"长度 + 两个角度"（球坐标）——它依然全是三角函数。

一句话的世界观：把机械臂看成"会动的三角函数"，把运动学看成"解一道几何题"。

1.3 机型选择：UR5 打主线，R1 作对照

平面臂（2–3 自由度）用三角函数即可直接求解，是极好的地基；但真实机械臂活在三维空间里。课程采用两台真实机械臂，路线是"2D 打地基 → 3D 起高楼"：

  • 前段（阶段二）用抽象的平面臂把 FK / IK 的几何思想讲透，认知负担最低；
  • 后段（阶段三、四）升维到真实机型：三维并没有推翻三角函数，只是把"一个角度"变成"多个角度"、把"圆"变成"球"、把"一次旋转"变成"旋转矩阵的堆叠"。

为什么主力用 UR5？

理由说明
推导最干净6 个关节的 axis 全是 0 0 1，相邻轴的 90° 夹角藏在关节原点的 rpy 里——这正是标准 DH 的 α 角，学生第一次能"看见"DH 参数长什么样
教科书标准UR5 的 DH 表广为流传，可与课程推导逐一对照；本仓库已用独立 DH 矩阵实现交叉验证（吻合到 1e-16）
解有限、限位宽除肘关节 ±180° 外全部 ±360°，多解不会被限位砍掉，"最多 8 组解"能完整看到
反例价值它偏偏不是球形手腕——恰好推翻课本那句常见的简化假设，是绝佳的批判性思维素材

为什么还要带上宇树 R1？

R1 是 7 轴仿生机械臂，比 UR5 多一个"冗余自由度"：同一目标位姿往往有无穷多组关节角。这既是难点，也是绝佳的"工程取舍"讨论素材（作为拓展层内容）。更妙的是：R1 的腕部反而比 UR5 更接近球形手腕（三轴偏差仅 5.0 mm，而 UR5 是 47.3 mm）——两台机器一对比，"课本假设 / 真实机型"的落差立刻变得具体可测。

数学基础

编程基础

缺口表现补救策略

三、教学目标（三维目标）

① 知识与理解

  1. 说清 FK 与 IK 的定义、区别与用途；
  2. 会用极坐标（平面）与球坐标（空间）表示位置；
  3. 掌握 1R / 2R / 3R 平面臂的 FK 与 IK 推导；
  4. 理解旋转矩阵的三角本质及欧拉角表示姿态；
  5. 理解 6-DOF 臂的位置—姿态解耦与腕心分解。

② 过程与能力

  1. 把物理问题抽象为几何模型并完成推导；
  2. 用 Python 实现 FK / IK 并借仿真验证；
  3. 分析多解、奇异位形、可达空间并做取舍；
  4. 对轨迹进行插值与平滑，让动作连贯。

③ 素养与价值

  1. 建立"数学是描述世界的工具，而非一堆题目"的观念；
  2. 发展计算思维（分解、抽象、自动化、容错）；
  3. 体验工程迭代：出错 → 定位 → 修正 → 再验证；
  4. 形成团队协作与成果表达能力。

每个模块统一给出：目标理论锚点关键推导代码任务仿真实操验收标准

阶段一 · 启航

M1机械臂怎么"知道"手在哪？2 课时
目标
建立 FK/IK 直觉，认识 UR5（主力）与宇树 R1（对照）两台真实机械臂，熟悉仿真平台。
理论锚点
运动学问题定义；"长度 + 角度"与"坐标"两种描述。
关键探究
教师拖动仿真关节，学生观察末端如何移动 → 引出"关节空间"与"笛卡尔空间"。
代码任务
调用 set_joints(q) 与 get_ee_pose()，打印几组关节角对应的末端位置，填表观察规律。
仿真实操
自由拖动关节，记录 5 组"角度 ↔ 位置"数据。
验收
能用自己的话说明 FK 与 IK 的区别，并指出"哪一步最像解三角形"。

阶段二 · 平面地基

M2单位圆与"角度坐标"1 课时
目标
把"角度"翻译为"位置坐标"，建立 (L, θ) → (x, y) 的语言。
理论锚点
x = L·cos θ, y = L·sin θ；弧度制与角度制互换。
关键推导
从单位圆出发，把半径 1 推广到连杆长度 L。
代码任务
实现 link_end(L, theta) -> (x, y)，用 matplotlib 画出旋转的连杆。
仿真实操
让单连杆匀速旋转，观察末端画出圆——"圆的方程就是 sin/cos"。
验收
能解释"为什么末端轨迹是圆"，并预测 θ=90°、180°、270° 时末端坐标。
M3平面正运动学：1R → 2R → 3R2 课时
目标
掌握多连杆正运动学；理解角度累加（复合旋转）。
理论锚点
x = L1·cos θ1 + L2·cos(θ1+θ2)，y = L1·sin θ1 + L2·sin(θ1+θ2)。
关键推导
第二个关节的角度为何是 θ1+θ2？——它相对上一个连杆转动，这是复合旋转的核心直觉，也是"变换链"的雏形。
代码任务
实现 fk_2r(L1, L2, th1, th2)，并推广到 3R。
仿真实操
固定 L1=L2，扫描 θ2 从 0° 到 180°，观察可达区域如何变化（从"点"到"面"）。
验收
预测一组 (θ1, θ2) 的末端坐标，与仿真对照，误差 < 1e-3。
M4平面逆运动学：余弦定理 + atan22 课时
目标
由目标位置反解关节角；理解多解与可达空间。
理论锚点
余弦定理 cos θ2 = (x²+y² − L1² − L2²)/(2·L1·L2)；θ1 = atan2(y,x) − atan2(L2·sin θ2, L1 + L2·cos θ2)。
关键推导
把"两连杆 + 目标点"构成三角形：余弦定理求"肘角"，atan2 定方向。强调 atan2 能正确处理四象限。
概念难点
多解（肘上/肘下）、可达空间（圆环 |L1−L2| ≤ r ≤ L1+L2）、奇异位形（完全伸直时 θ2 敏感）。
代码任务
实现 ik_2r(L1, L2, x, y)（返回两组解），作图验证正解能回到原目标。
仿真实操
同一目标分别以"肘上/肘下"到达并比较；拖到边界外观察"不可达"。
验收
一目标点求出两条解，均能通过 FK 回到目标；能画出可达空间（圆环）。
M5轨迹初探：关节空间 vs 笛卡尔空间1 课时
目标
让末端沿一条路径移动；理解两种空间的取舍。
理论锚点
插值思想；直线路径在关节空间里通常不是直线。
关键推导
把"从 A 到 B 走直线"离散成若干中间点，对每点调用 IK → 得到一串关节角序列。
代码任务
实现 draw_line(A, B, n)：采样 n 点 → 逐个 IK → 依次 set_joints。
仿真实操
让末端画出直线与圆；观察"每帧都要解一次 IK"。
验收
末端能画出规定的直线与圆，轨迹点误差 < 2% 臂长。

阶段三 · 升维

M6三维坐标与球坐标：三角的升维2 课时
目标
把平面极坐标推广到空间球坐标，理解"多一个自由角度"。
理论锚点
x = r·sin φ·cos θ，y = r·sin φ·sin θ，z = r·cos φ。
关键推导
先固定 φ=90°，发现它退化成平面极坐标；再放开 φ，观察 z 分量如何出现——"升维 = 增加一个角度余弦"。
代码任务
实现 sph2cart(r, theta, phi) 与反向 cart2sph。
仿真实操
让末端在球面上移动，观察两个角度分别控制"经度"与"纬度"。
验收
球坐标 ↔ 直角坐标互算，往返误差 < 1e-6。
M7旋转矩阵的三角本质与姿态2 课时
目标
理解姿态表示；看懂旋转矩阵里全是 sin/cos。
理论锚点
Rz(α) 的 9 个元素皆为 0 / ±1 / ±sin / ±cos（绕 y、x 轴同理）。
关键推导
逐列拆解：矩阵第一列 = "原 x 轴旋转后的新坐标" = (cos α, sin α)。学生亲手算出 Ry、Rx，建立"矩阵 ≠ 黑魔法"的观念。
概念难点
位置 vs 姿态；旋转顺序会影响结果（矩阵乘法不可交换）。
代码任务
实现 Rz(α)、Ry(β)、Rx(γ)，验证 Rz(90°)·(1,0,0) = (0,1,0)。
仿真实操
依次绕三轴旋转末端，比较不同旋转顺序的结果。
验收
能手写三个基本旋转矩阵；能解释"先转 z 再转 y ≠ 先转 y 再转 z"。
M8UR5 结构拆解 + DH 与三维正运动学（变换链）2 课时
目标
看懂真实 UR5 的结构；用"变换链"算出末端位姿；第一次见到 DH 参数的真身。
理论锚点
末端位姿 = 各关节变换依次相乘：T = T1·T2·…·T6。
关键推导
每个 Ti = "固定平移(装在哪) × 固定旋转(朝哪边) × 绕本关节轴转 q"；这与 M3 中"角度累加"是完全相同的思想，只是从 2D 升到 3D。
★ 啊哈时刻
打开 UR5 的 URDF 会发现——6 个关节的 axis 全是 0 0 1！那 90° 的夹角去哪了？答案藏在关节原点的 rpy 里：<origin xyz="0 0 0" rpy="1.570796327 0 0"/>——这个 π/2 就是 DH 的 α₁。学生在这一刻会真正理解 DH 表不是凭空规定的。
概念难点
DH 四参数（a 连杆长 / d 偏置 / α 扭角 / θ 关节角）的直觉版（点到为止）。
代码任务
写好 rot_x / rot_y / rot_z 三块旋转积木（M7），平台自动拼出 UR5 完整正运动学——关节转用 rot_z、原点 rpy 里的 π/2 用 rot_x，三块积木全部会被真正调用。
仿真实操
设置关节角观察 UR5 姿态变化；用"平面 2R 类比"（只动 shoulder_lift + elbow）看末端被锁在竖直平面内。
验收
自实现 FK 与真值误差 < 1e-9；能指出 UR5 关节原点里哪个 rpy 分量对应 DH 的哪个 α。

阶段四 · 三维逆解

⚠️ 阶段四的核心修正：不要假设"球形手腕"
教科书常说"六轴臂最后三根轴交于一点（球形手腕），于是位置与姿态可以解耦"。本课程要求学生亲手检验这句话，因为对 UR5 它不成立：
检查项UR5 实测宇树 R1 实测
轴 4 ∩ 轴 5相交相距 0.70 mm
轴 5 ∩ 轴 6相交相距 10.00 mm
轴 4 ∥ 轴 6平行，相距 94.65 mm相交
三轴共点❌ 最大偏差 47.33 mm❌ 但偏差仅 5.01 mm（近似球形）
后果：只转 wrist_1 90°，UR5 末端就移动 133.9 mm。所以"位置只由前三个关节决定"只是近似。
教学处理：经典解耦推导降级为"子问题级方法"——平面 2R 逆解、欧拉角反解本身都是正确且必须掌握的工具；但要明确它们是局部正确、整体近似，并用数值 IK 真值对照让学生量化看到偏差。这个"发现课本假设失效"的过程，正是本课程最有价值的探究环节。
复现命令：python demos/demo_wrist_geometry.py（详见 docs/04）
M9位置逆解：球坐标 + 余弦定理（子问题）与腕部耦合2 课时
目标
会用几何分解求"管位置"的关节角；理解几何分解在什么时候成立、什么时候失效。
理论锚点
腕心（wrist center）思想：设法找到一个点，使它的位置只由前几个关节决定，从而把问题拆成"管位置 + 管姿态"两半。
关键推导
① 先建"理想情形"：若最后三轴交于一点 p_wc，则 p_wc = p_goal − d·(目标 z 轴方向)，位置问题独立出来；② 对 p_wc 用球坐标求底座方位角、用余弦定理 + atan2 求两个俯仰角——这就是 M4 平面 2R 思想在空间中的落点；③ 然后检验：UR5 三轴不共点，p_wc 并不真正独立于腕角。
代码任务
复用 M4 的 ik_2r 写出肩肘几何解；整臂解析解的复杂度由平台数值 IK 兜底对照。
仿真实操
给定目标点先解位置关节，观察腕心是否对准预期；再转动腕关节，看腕心也会跟着动——亲手推翻假设。
验收
解出的位置关节经 FK 后误差 < 1e-3；能用自己的话解释"为什么 UR5 上不能严格解耦"。
M10姿态逆解：欧拉角与"球形手腕"假设的实测检验2 课时
目标
由目标姿态解出腕部关节角；用数据判定"球形手腕"是否成立。
理论锚点
已知目标旋转矩阵 → 反解欧拉角；若三轴交于一点，则姿态问题与位置问题完全分离。
关键推导
展开 Rz·Ry·Rx，用矩阵元素之比构造 atan2 逐个解出腕部三关节——全程仍是 atan2 与 sin/cos，呼应 M7。三块旋转积木在这里第二次派上用场。
★ 探究实验
① 用 wrist_report() 算两机三轴两两距离：UR5 轴 4 ∥ 轴 6 相距 94.650 mm；R1 三轴偏差仅 5.01 mm。② 只转一个腕关节 90° 测末端位移：UR5 的 wrist_1/wrist_2 分别带动末端 133.9 / 116.4 mm，wrist_3 为 0。③ 查阅文献复核（MDPI Robotics 12(3):71, 2023；arXiv:2510.19081）——学会实测 + 文献双重复核。
概念难点
万向节死锁（gimbal lock）：腕部中间角为 ±90° 时两个角度同时生效、丢失一个自由度；对应 R1（J6 仅 ±30°）与 UR5（shoulder_lift/wrist_2 对齐时）的奇异位形。
代码任务
实现 euler_zyx_from_matrix(R) 与 matrix_from_euler_zyx(...)。
仿真实操
给定一串目标姿态，解出腕角并让仿真末端对齐；同时记录末端位置的"意外"漂移量。
验收
姿态矩阵往返误差 < 1e-9；能指出死锁发生在哪组角度；能给出"UR5 不是球形手腕"的量化证据。
M11整合、多解、奇异与冗余：UR5 ↔ R1 对照2 课时
目标
拼出完整 IK；系统认识多解、奇异与冗余自由度；通过两台机器的对照理解"构型决定难度"。
理论锚点
完整 IK = 位置解（M9）+ 姿态解（M10）；6 轴臂最多 8 组解（肩×肘×腕各两种）；7 轴臂则有无穷多组。
关键推导
① UR5（6 轴）：从有限解里挑——关节限位 / 离奇异最远 / 离当前位形最近；UR5 限位宽（除肘外 ±360°），8 组解基本都能看到。② R1（7 轴）：方程 6 个、未知数 7 个 → 解集是一维流形，必须引入选解准则；R1 限位窄（J6 仅 ±30°），筛选更受约束。
代码任务
在可解子结构上实现多解返回与筛选，与平台数值 IK 对照；对 R1 额外实现"冗余最优"选解。
★ 双机对照
同一段目标轨迹分别让 UR5 与 R1 跟随，比较关节曲线上限位/速度的紧张程度。
验收
对同一目标给出多组合法解并说明取舍；能解释"哪些目标不可达、冗余自由度为什么有用"；能列出两台机器至少 3 条结构性差异。

七、仿真平台接口契约（供平台准备时对齐）

以下为建议的 Python API 契约。准备仿真平台 / 代码 / 模型文件时，按此封装即可与课程无缝对接。推荐引擎：PyBullet（纯 Python、易上手）或 MuJoCo（更精细）；也可用 THREE.js / CoppeliaSim 等。
class ArmBot:
    """机械臂仿真接口（建议在平台上优先实现，两台机型共用）"""

    # —— 状态读写 ——
    def set_joints(self, q):            # q: 关节角列表（弧度）；UR5 长度 6，R1 长度 7
    def get_joints(self) -> list:       # 返回当前关节角
    def get_ee_pose(self) -> (pos, R):  # 末端位置(3,)与姿态矩阵(3,3) —— 真值
    def reset(self):                    # 复位到初始姿态

    # —— 运动 ——
    def move_joints(self, q, steps=50): # 关节空间平滑运动
    def move_to(self, pos, R=None, steps=50):   # 平台IK移动到目标位姿（对照用）
    def draw_path(self, points, R=None):        # 让末端依次经过一串点位

    # —— 结构与辅助 ——
    def joint_limits(self) -> list:     # 各关节限位 [(lo,hi), ...]
    def reachable(self, pos) -> bool:   # 目标是否可达（可选）
    def show(self):                     # 渲染/刷新画面

附录 A · 关键公式速查

① 平面连杆末端（极坐标 → 直角坐标）

x = L·cos θ
y = L·sin θ

② 2R 平面正运动学（FK）

x = L1·cos θ1 + L2·cos(θ1 + θ2)
y = L1·sin θ1 + L2·sin(θ1 + θ2)

③ 2R 平面逆运动学（IK）—— 余弦定理

cos θ2 = (x² + y² − L1² − L2²) / (2·L1·L2)
θ1 = atan2(y, x) − atan2(L2·sin θ2,  L1 + L2·cos θ2)

可达条件：|L1 − L2| ≤ √(x² + y²) ≤ L1 + L2

④ 球坐标（空间位置）

x = r·sin φ·cos θ
y = r·sin φ·sin θ
z = r·cos φ

⑤ 基本旋转矩阵（绕 z 轴 α）

Rz(α) = [ cos α  −sin α  0 ]
        [ sin α   cos α  0 ]
        [   0       0     1 ]   （Ry、Rx 结构同理）

⑥ 变换链（三维正运动学）

T_end = T1 · T2 · T3 · T4 · T5 · T6

⑦ 核心函数提示

atan2(y, x)  →  返回 (−π, π]，自动处理四个象限

## 4. 结构解读（教学用）

按旋转轴分组：

- **绕 z 轴**：J1（底座回转）、J7（末端自转）
- **绕 x 轴**：J2、J4、J6 —— 主要"俯仰"关节
- **绕 y 轴**：J3、J5 —— 主要"滚转"关节

据此可以给学生这样一张"功能地图"：

| 部位 | 关节 | 作用 | 课程落点 |
|---|---|---|---|
| 底座 | J1 | 决定机械臂"朝向哪个方位" | M6 球坐标（方位角 θ） |
| 肩 + 肘 | **J2、J4** | 同一类俯仰关节，构成"平面 2R 臂"的类比 | **M3/M4 平面正/逆运动学** |
| 臂平面 | J3 | 把整条臂的"工作平面"摆到想要的倾角 | M6 球坐标（极角 φ） |
| 腕部 | J5、J6、J7 | 三轴**近似**交于一点 → 近似球形手腕，负责末端姿态 | **M10 欧拉角** |

> **教学提示**：R1 的 J2 与 J4 是两根平行的"俯仰轴"，这正是课程用平面 2R 打地基的现实依据；
> J1（方位）与 J3（倾角）负责把这条平面臂"摆"到三维空间的任意朝向上——**球坐标的两个角**。

### 4.1 腕部几何实测（J5/J6/J7）

用 `armblocks.core.geometry.wrist_report()` 量出的三轴相对位置：

| 轴对 | 最短距离 | 是否相交 |
|---|---|---|
| J5 – J6 | 0.700 mm | 否（近乎相交） |
| J5 – J7 | **0.000 mm** | ✅ 相交 |
| J6 – J7 | 10.000 mm | 否 |

到"最接近公共点"的最大偏差 **5.01 mm** —— 所以 R1 的手腕是**近似**球形、而非严格球形。
（对比：UR5 偏差 **47.33 mm**，且轴 4 与轴 6 平行。也就是说 R1 反而更接近课本里的理想模型。）

复现：`python demos/demo_wrist_geometry.py`

## 5. 建模与仿真注意点

1. **网格路径是相对的**：`meshes/*.STL` 必须与 `R1_7a.urdf` 保持同级目录。
2. **常用加载方式**：
   - Python 原生解析：`armblocks.core.urdf_model.load_model("models/r1_7a/R1_7a.urdf")`
   - PyBullet：`pybullet.loadURDF("models/r1_7a/R1_7a.urdf")`（需 `useFixedBase=True`）
   - MuJoCo：需先由 URDF 转换为 MJCF
3. **零位末端**：全 0 关节角时，末端 Link7 位于 base 上方约 **(0.003, −0.034, 0.193) m**。
4. **冗余自由度**：7 DOF 相对"6 维任务空间"多出 1 个自由度 → 同一目标位姿通常有**无穷多组**解。课程把它作为 M11 的拓展讨论点（如何用冗余绕开奇异与限位）。
5. **奇异位形**：当腕部中间角接近 ±90°（J6 侧）或臂完全伸直时，雅可比矩阵降秩，关节角速度会暴涨。

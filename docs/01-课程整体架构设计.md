## 一、课程定位与设计理念

### 1.1 一个驱动问题（Driving Question）

> **机械臂只有几个"会转的关节"，它怎么"知道"自己的手在空间的什么地方、朝向哪里？
> 反过来，我想让它的手精准到达某个位置和姿态，它又该怎么算每个关节要转多少度？**

这个"正着算"（**正运动学 FK**）与"反着算"（**逆运动学 IK**）的问题，是机器人学的第一道门槛，也**恰好是一道纯粹的三角几何题**。本课程的全部设计，都围绕这句话展开。

### 1.2 核心理念：三角函数是"空间的语言"

高中课上的三角函数，常常被当作"算三角形边角"的解题工具。本课程要传递一个更大的观念：

- **sin、cos 的本质是坐标**——单位圆上一个角度 θ，对应的点就是 `(cos θ, sin θ)`；
- 一根长度固定、只能绕一端转动的**连杆**，它的末端坐标就是 `(L·cos θ, L·sin θ)`——三角函数就是"角度→位置"的翻译器；
- 机械臂 = 一串连杆 = 一串三角函数的**叠加与复合**；
- 平面上的"长度 + 角度"（极坐标），在空间中自然升维成"长度 + 两个角度"（**球坐标**）——它依然全是三角函数。

一句话概括课程世界观：**把机械臂看成"会动的三角函数"，把运动学看成"解一道几何题"。**

### 1.3 机型选择：UR5 打主线，R1 作对照

平面臂（2–3 自由度）用三角函数即可直接求解，是极好的地基；但真实机械臂活在三维空间里。本课程采用**两台真实机械臂**，路线是"**2D 打地基 → 3D 起高楼**"：

- **前段（阶段二）**用抽象的平面臂把 FK / IK 的几何思想讲透，认知负担最低；
- **后段（阶段三、四）**升维到真实机型：让学生发现三维并没有推翻三角函数，只是把"一个角度"变成"多个角度"、把"圆"变成"球"、把"一次旋转"变成"旋转矩阵的堆叠"。

**为什么主力用 UR5？**

| 理由 | 说明 |
|---|---|
| 推导最干净 | 6 个关节的 `axis` **全是 `0 0 1`**，相邻轴的 90° 夹角藏在**关节原点的 `rpy`** 里 —— 这正是标准 DH 的 **α 角**，学生第一次能"看见"DH 参数长什么样 |
| 教科书标准 | UR5 的 DH 表广为流传，可与课程推导逐一对照；本仓库已用独立 DH 矩阵实现交叉验证（吻合到 1e-16） |
| 解有限、限位宽 | 除肘关节 ±180° 外全部 ±360°，多解不会被限位砍掉，"最多 8 组解"能完整看到 |
| 反例价值 | **它偏偏不是球形手腕** —— 恰好推翻课本那句常见的简化假设，是绝佳的批判性思维素材 |

**为什么还要带上宇树 R1？**

R1 是 7 轴仿生机械臂，比 UR5 **多一个"冗余自由度"**：同一目标位姿往往有**无穷多组**关节角。
这既是难点，也是绝佳的"工程取舍"讨论素材（本课程作为**拓展层**内容）。
更妙的是：**R1 的腕部反而比 UR5 更接近球形手腕**（三轴偏差仅 5.0 mm，而 UR5 是 47.3 mm）
—— 两台机器一对比，"课本假设 / 真实机型"的落差立刻变得具体可测。

> **教学取舍（重要）**：两台机器的关节轴排布都不简单，因此课程采用**分层策略**：
> ① 用平面 2R 把几何原理讲透（阶段二）；
> ② 用"旋转矩阵积木"搭出**完整正运动学**——三块旋转积木写对，两台真实机械臂的 FK 都能精确复现（阶段三）；
> ③ 逆运动学的**解析推导**放在可解子问题上（平面 2R、欧拉角），**整臂 IK 用平台的数值解作为真值对照**（阶段四）。
> 这样既保住"三角函数能算清"的爽感，又不回避真实机械臂的复杂性。

### 1.4 三条设计原则

| 原则 | 含义 | 落地方式 |
|---|---|---|
| **理论带动实践** | 先弄清"为什么"，再动手做"怎么做" | 每个模块先推导公式，再写代码 |
| **代码转化成实操** | 代码不是终点，而是驱动机械臂"动起来"的手 | 每段代码都对应一次仿真演示与验收 |
| **预测—验证闭环** | 数学推导的答案必须能被仿真检验 | 学生先手算预测，再跑仿真比对误差 |

## 二、学情分析

### 2.1 学生已具备（有基础 Python）

**数学**：任意角三角函数、弧度制、单位圆、正弦/余弦定理、两点间距离公式、平面向量初步、空间直角坐标系（多数已学）。

**编程**：变量、列表、循环、函数、条件判断、库调用（`numpy` / `matplotlib` 基础）。

### 2.2 认知缺口与难点

| 缺口 | 表现 | 补救策略 |
|---|---|---|
| **空间想象力** | 难以在脑中"转动"三维物体 | 大量动画可视化；先 2D 后 3D；用实物手势辅助 |
| **旋转矩阵的抽象感** | 觉得矩阵是"黑魔法" | 明确"矩阵 = 一批 sin/cos 的打包"，逐列讲每个元素来自哪条三角关系 |

| **多解 & 奇异位形** | 概念抽象、不易理解为何"有时无解" | 用"肘上/肘下"手势 + 可达空间可视化 |
| **数学 ↔ 代码的对应** | 会推公式但不知如何写成代码 | 提供"填空式"代码骨架，公式与函数逐行对照 |
| **调试能力** | 出错后不会定位 | 引入"预测—验证"日志表与调试清单 |

弧度与角度互换、`atan2` 的四象限含义、`numpy` 数组基本操作、仿真平台的基本操作。

## 三、教学目标（三维目标）

### 3.1 知识与理解

1. 说清**正运动学（FK）与逆运动学（IK）**的定义、区别与各自用途；
2. 理解并会用**极坐标（平面）与球坐标（空间）**用三角函数表示位置；
3. 掌握 **1R / 2R / 3R 平面臂**的 FK 与 IK 几何推导；
4. 理解**旋转矩阵的三角本质**及**欧拉角**表示姿态的思路；
5. 理解 6-DOF 臂的**位置—姿态解耦思想**、DH 参数的由来，以及**解耦在真实机型上为何只是近似**
   （UR5 的腕轴不共点，见 `docs/04`）；
6. 理解**冗余自由度**（7 轴的 R1）与**选解准则**的意义。

### 3.2 过程与能力

1. 能把物理问题**抽象为几何模型**并独立完成公式推导；
2. 能用 Python **实现 FK / IK** 并借助仿真**验证正确性**；
3. 能分析**多解、奇异位形、可达空间**，并做出工程取舍；
4. 能对轨迹进行**插值与平滑**，让机械臂动作连贯。

### 3.3 素养与价值

1. 建立"**数学是描述世界的工具，而非一堆题目**"的观念；
2. 发展**计算思维**（分解、抽象、自动化、容错）；
3. 体验**工程迭代**：出错 → 定位 → 修正 → 再验证；
4. 形成**团队协作与成果表达**能力。

## 五、统一教学节奏："探—推—写—验"四步循环

每一个模块都遵循同一套节奏，让学生形成稳定的学习预期，也保证"理论带动实践"落到实处：

```
① 探（提出问题）  2D/3D 中的一个具体现象或挑战，激发疑问
        ↓
② 推（理论推导）  学生在纸面/白板上用三角函数独立推导公式  ← 理论核心
        ↓
③ 写（代码实现）  把公式逐行翻译成 Python 函数（填空式骨架）  ← 代码桥梁
        ↓
④ 验（仿真验证）  运行仿真机械臂，与手算预测值对照，做误差分析  ← 实操闭环
```

### "预测—验证"日志表（每模块必填）

| 关节角 / 目标 | 我的手算预测 | 仿真真值 | 误差 | 差异原因 |
|---|---|---|---|---|
| 例：θ1=30°, θ2=45° | 末端 ≈ (?, ?) | (?, ?) | ? | — |

> **设计意图**：让数学推导的结论始终被仿真"审判"。当预测与真值不符时，学生被迫回到公式找 bug——这正是最有价值的学习时刻。

## 六、模块详解

> 每个模块统一给出：**目标 / 理论锚点 / 关键推导 / 代码任务 / 仿真实操 / 验收标准**。

### 阶段一 · 启航

#### M1　机械臂怎么"知道"手在哪？（2 课时）

- **目标**：建立 FK/IK 的直觉，认识 **UR5（主力）与宇树 R1（对照）**两台真实机械臂，熟悉仿真平台。
- **理论锚点**：运动学问题定义；"长度 + 角度"与"坐标"的两种描述。
- **关键探究**：教师拖动仿真关节，学生观察末端如何移动 → 引出"关节空间"与"笛卡尔空间"；顺带对比两台机器"长什么样、能伸多远"。
- **代码任务**：调用 `set_joints(q)` 与 `get_ee_pose()`，打印几组关节角对应的末端位置，填表观察规律。（`python demos/demo_compare_arms.py` 可直接得到两机对照表）
- **仿真实操**：自由拖动关节，记录 5 组"角度 ↔ 位置"数据。
- **验收**：能用自己的话说明 FK 与 IK 的区别；能说出 UR5 与 R1 至少 3 条外观/规格上的差异（自由度、臂展、轴数）。

---

### 阶段二 · 平面地基

#### M2　单位圆与"角度坐标"（1 课时）

- **目标**：把"角度"翻译为"位置坐标"，建立 `(L, θ) → (x, y)` 的语言。
- **理论锚点**：单位圆；`x = L·cos θ, y = L·sin θ`；弧度制与角度制互换。
- **关键推导**：从单位圆出发，把半径 1 推广到连杆长度 L。
- **代码任务**：实现 `link_end(L, theta) -> (x, y)`，用 `matplotlib` 画出一根旋转的连杆。
- **仿真实操**：让单连杆匀速旋转，观察末端画出**圆**——"圆的方程就是 sin/cos"。
- **验收**：能解释"为什么末端轨迹是圆"，并预测 θ=90°、180°、270° 时末端坐标。

#### M3　平面正运动学：1R → 2R → 3R（2 课时）

- **目标**：掌握多连杆正运动学；理解角度**累加**（复合旋转）。
- **理论锚点**：单连杆 → 双连杆末端坐标：
  `x = L1·cos θ1 + L2·cos(θ1+θ2)`，`y = L1·sin θ1 + L2·sin(θ1+θ2)`。
- **关键推导**：为什么第二个关节的角度要写成 `θ1+θ2`？——因为它是**相对上一个连杆**转的，这是复合旋转的核心直觉，也是后面"变换链"的雏形。
- **代码任务**：实现 `fk_2r(L1, L2, th1, th2) -> (x, y)`，并推广到 3R。
- **仿真实操**：固定 L1=L2，扫描 θ2 从 0° 到 180°，观察可达区域如何变化（从"点"到"面"）。
- **验收**：预测一组 (θ1, θ2) 的末端坐标，与仿真对照，误差 < 1e-3。

#### M4　平面逆运动学：余弦定理 + atan2（2 课时）

- **目标**：由目标位置反解关节角；理解多解与可达空间。
- **理论锚点**：
  - 余弦定理：`cos θ2 = (x²+y² − L1² − L2²) / (2·L1·L2)`
  - 方向角：`θ1 = atan2(y, x) − atan2(L2·sin θ2, L1 + L2·cos θ2)`
- **关键推导**：把"两连杆 + 目标点"构成三角形，用余弦定理求"肘角"，用 atan2 定方向。强调 `atan2` 相比 `arctan` 能正确处理四个象限。
- **概念难点**（重点讲解）：
  - **多解**：肘上 / 肘下两组解，都合法；
  - **可达空间**：由 `|L1−L2| ≤ r ≤ L1+L2` 决定，形状是**圆环**；
  - **奇异位形**：手臂完全伸直时 θ2=0，微小的目标移动会引起 θ2 剧烈变化。
- **代码任务**：实现 `ik_2r(L1, L2, x, y) -> (th1, th2)`（返回两组解），并作图验证正解能回到原目标。
- **仿真实操**：给定同一个目标，让机械臂分别以"肘上""肘下"姿态到达，比较差异；拖到边界外观察"不可达"。
- **验收**：一目标点求出两条解，均能通过 FK 回到目标；能画出手臂的可达空间（圆环）。

#### M5　轨迹初探：关节空间 vs 笛卡尔空间（1 课时）

- **目标**：让末端沿一条路径移动；理解两种空间的取舍。
- **理论锚点**：插值思想；直线路径在关节空间里通常**不是直线**。
- **关键推导**：把"从 A 到 B 走直线"离散成若干中间点，对每个点调用 IK → 得到一串关节角序列。
- **代码任务**：实现 `draw_line(A, B, n)`：采样 n 个点 → 逐个 IK → 依次 `set_joints`。
- **仿真实操**：让末端画出一条直线、一个圆；观察"每帧都要解一次 IK"。
- **验收**：末端能画出规定的直线与圆，轨迹点误差 < 2% 臂长。

### 阶段三 · 升维

#### M6　三维坐标与球坐标：三角的升维（2 课时）

- **目标**：把平面极坐标推广到空间球坐标，理解"多一个自由角度"。
- **理论锚点**：
  `x = r·sin φ·cos θ`，`y = r·sin φ·sin θ`，`z = r·cos φ`
  （r：半径，φ：极角/仰角，θ：方位角）
- **关键推导**：先固定 φ=90°，发现它退化成平面极坐标；再放开 φ，观察 z 分量如何出现——**"升维 = 增加一个角度余弦"**。
- **代码任务**：实现 `sph2cart(r, theta, phi) -> (x, y, z)` 并做反向 `cart2sph`。
- **仿真实操**：让末端在一张**球面**上移动，观察两个角度如何分别控制"经度"和"纬度"。
- **验收**：给定球坐标能算出直角坐标，反之亦然（往返误差 < 1e-6）。

#### M7　旋转矩阵的三角本质与姿态（2 课时）

- **目标**：理解姿态的表示；看懂旋转矩阵里全是 sin/cos。
- **理论锚点**：绕 z 轴旋转 α 的矩阵
  ```
  Rz(α) = [ cos α  −sin α  0 ]
          [ sin α   cos α  0 ]
          [   0       0     1 ]
  ```
  （绕 y、x 轴的矩阵同理，元素皆为 0/±1/±sin/±cos）
- **关键推导**：**逐列拆解**——矩阵第一列就是"原 x 轴旋转后的新坐标"，而它就是 `(cos α, sin α)`。让学生亲手算出 Ry、Rx，建立"矩阵 ≠ 黑魔法，矩阵 = 一批三角关系的打包"的观念。
- **概念难点**：位置 vs 姿态；旋转的**顺序**会影响结果（矩阵乘法不可交换）。
- **代码任务**：实现 `Rz(α)`、`Ry(β)`、`Rx(γ)`，并验证 `Rz(90°)·(1,0,0) = (0,1,0)`。
- **仿真实操**：依次绕三个轴旋转末端，观察姿态变化；对比不同的旋转顺序。
- **验收**：能手写三个基本旋转矩阵；能解释"为什么先转 z 再转 y ≠ 先转 y 再转 z"。

#### M8　UR5 结构拆解 + DH 与三维正运动学（2 课时）

- **目标**：看懂真实 UR5 的结构；用"变换链"算出末端位姿；第一次见到 DH 参数的真身。
- **理论锚点**：变换链思想——**末端位姿 = 各关节变换依次相乘**；串联臂"后一个关节的坐标系建立在前一个之上"。
- **关键推导**：把 6 个关节写成 `T = T1·T2·…·T6`，每个 `Ti` = "固定平移（装在哪）× 固定旋转（朝哪边）× 绕本关节轴转 q"；强调这与 M3 中"角度累加"是完全相同的思想，只是从 2D 升到了 3D。
- **★ 本模块的"啊哈"时刻**：打开 UR5 的 URDF 会发现 —— **6 个关节的 `axis` 全都是 `0 0 1`**！那 90° 的夹角去哪了？答案是**藏在关节原点的 `rpy` 里**：
  ```xml
  <joint name="shoulder_lift_joint" type="revolute">
    <origin xyz="0 0 0" rpy="1.570796327 0 0"/>   <!-- ← 这个 π/2 就是 DH 的 α₁ -->
    <axis xyz="0 0 1"/>
  </joint>
  ```
  这正是**标准 DH 参数里的 α 角**的物理含义："上一根轴和这一根轴相差 90°"。学生在这一刻会真正理解 DH 表不是凭空规定的。
- **概念难点**（点到为止）：DH 四参数（a 连杆长 / d 偏置 / α 扭角 / θ 关节角）的直觉版。
- **代码任务**：**写好 `rot_x / rot_y / rot_z` 三块旋转积木**（M7），平台自动用它们拼出 UR5 的完整正运动学 —— 因为关节转用 `rot_z`、原点 rpy 里的 π/2 用 `rot_x`，**三块积木全部会被真正调用**。
- **仿真实操**：设置关节角，观察 UR5 的姿态变化；用"平面 2R 类比"（只动 shoulder_lift + elbow）看末端被锁在竖直平面内。
- **验收**：自实现 FK 与平台真值误差 < 1e-9；能指出 UR5 关节原点里哪个 `rpy` 分量对应 DH 的哪个 α。

### 阶段四 · 三维逆运动学

> ### ⚠️ 阶段四的核心修正：不要假设"球形手腕"
>
> 教科书常说："六轴臂最后三根轴交于一点（球形手腕），于是位置与姿态可以解耦。"
> **本课程要求学生亲手检验这句话**，因为对 UR5 它**不成立**：
>
> | 检查项 | UR5 实测 | 宇树 R1 实测 |
> |---|---|---|
> | 轴 4 ∩ 轴 5 | 相交 | 相距 0.70 mm |
> | 轴 5 ∩ 轴 6 | 相交 | 相距 10.00 mm |
> | **轴 4 ∥ 轴 6** | **平行，相距 94.65 mm** | 相交 |
> | 三轴共点 | ❌ 最大偏差 **47.33 mm** | ❌ 但偏差仅 **5.01 mm**（近似球形） |
>
> 后果：只转 `wrist_1` 90°，UR5 末端就移动 **133.9 mm**。
> 所以"位置只由前三个关节决定"只是**近似**。
>
> **教学处理**：经典的解耦推导**降级为"子问题级别的方法"** —— 平面 2R 逆解、欧拉角反解本身
> 都是正确的、必须掌握的工具；但要明确它们是**局部正确、整体近似**，并用
> **数值 IK 真值对照**让学生量化看到偏差。这个"发现课本假设失效"的过程，
> 正是本课程最有价值的探究环节。
>
> 复现命令：`python demos/demo_wrist_geometry.py`（见 `docs/04`）

#### M9　位置逆解：球坐标 + 余弦定理（子问题）与腕部耦合（2 课时）

- **目标**：会用几何分解求"管位置"的关节角；理解几何分解**在什么时候成立、什么时候失效**。
- **理论锚点**：**腕心（wrist center）**思想——设法找到一个点，使它的位置只由前几个关节决定，从而把问题拆成"管位置 + 管姿态"两半。
- **关键推导**：
  1. 先建立"理想情形"：若最后三轴交于一点 `p_wc`，则 `p_wc = p_goal − d·(目标 z 轴方向)`，于是位置问题独立出来；
  2. 对 `p_wc` 用**球坐标**求底座方位角，用**余弦定理 + atan2** 求两个俯仰角 —— 这就是 M4 平面 2R 思想在空间中的落点；
  3. **然后检验**：UR5 的三轴不共点，所以 `p_wc` 并不真正独立于腕角。让学生用 `core/geometry.wrist_report()` 量出偏差，并讨论"工程上如何修正"。
- **代码任务**：复用 M4 的 `ik_2r`，写出肩肘几何解；整臂解析解的复杂度由平台的数值 IK 兜底对照。
- **仿真实操**：给定目标点，先解位置关节，观察腕心是否对准预期；再转动腕关节，看腕心**也会跟着动**——亲手推翻假设。
- **验收**：解出的位置关节经 FK 后误差 < 1e-3；能用自己的话解释"为什么 UR5 上不能严格解耦"。

#### M10　姿态逆解：欧拉角与"球形手腕"假设的实测检验（2 课时）

- **目标**：由目标姿态解出腕部关节角；用数据判定"球形手腕"是否成立。
- **理论锚点**：已知目标旋转矩阵 → 反解**欧拉角**；若三轴交于一点，则姿态问题与位置问题完全分离。
- **关键推导**：把 `Rz·Ry·Rx` 展开，用矩阵元素之比构造 `atan2`，逐个解出腕部关节角——**全程仍是 atan2 与 sin/cos**，呼应 M7。三块旋转积木在这里第二次派上用场。
- **★ 探究实验（本模块高潮）**：
  1. 用 `wrist_report()` 算出两机的三轴两两距离，判定是否共点：
     ```
     UR5：轴 4 ∥ 轴 6，相距 94.650 mm  → 不是球形腕
     R1 ：三轴偏差仅 5.01 mm             → 近似球形腕
     ```
  2. 只转一个腕关节 90°，测末端位移：UR5 的 `wrist_1`/`wrist_2` 分别带动末端 **133.9 / 116.4 mm**，`wrist_3` 为 0 mm；
  3. 查证：这一结论有文献支持（MDPI *Robotics* 12(3):71, 2023；arXiv:2510.19081）——学生学会**用实测 + 文献双重复核**。
- **概念难点**：万向节死锁（gimbal lock），腕部中间角为 ±90° 时两个角度同时生效、丢失一个自由度；对应 R1（J6 仅 ±30°）与 UR5（`shoulder_lift`/`wrist_2` 对齐时）的奇异位形。
- **代码任务**：实现 `euler_zyx_from_matrix(R) -> (α, β, γ)` 与 `matrix_from_euler_zyx(...)`。
- **仿真实操**：给定一串目标姿态，解出腕角并让仿真末端对齐；同时记录末端位置的"意外"漂移量。
- **验收**：姿态矩阵往返误差 < 1e-9；能指出死锁发生在哪组角度；能给出"UR5 不是球形手腕"的量化证据。

#### M11　整合、多解、奇异与冗余：UR5 ↔ R1 对照（2 课时）

- **目标**：拼出完整 IK；系统认识多解、奇异与**冗余自由度**；通过两台机器的对照理解"构型决定难度"。
- **理论锚点**：完整 IK = 位置解（M9）+ 姿态解（M10）；6 轴臂最多 **8 组解**（肩×肘×腕各两种）；7 轴臂则有**无穷多组**。
- **关键推导**：
  1. **UR5（6 轴）**：从有限解里挑 —— 关节限位 / 离奇异最远 / 离当前位形最近；UR5 限位宽（除肘外 ±360°），8 组解基本都能看到；
  2. **R1（7 轴）**：方程 6 个、未知数 7 个 → 解集是一维流形，必须引入**选解准则**（离限位最远 / 关节运动量最小 / 避开障碍）；R1 限位窄（J6 仅 ±30°），筛选更受约束。
- **代码任务**：在可解子结构上返回多组合法解，与平台数值 IK 对照；对 R1 额外实现"冗余最优"选解。
- **仿真实操**：同一目标，用不同解到达并观察关节运动量差异；构造不可达点与奇异点。
- **★ 双机对照实验**：同一段目标轨迹，分别让 UR5 与 R1 跟随，比较关节曲线上限位/速度的紧张程度。
- **验收**：能对同一目标给出多组合法解并说明取舍理由；能解释"哪些目标不可达、冗余自由度为什么有用"；能列出台机器的至少 3 条结构性差异。

### 阶段五 · 综合项目

#### M12　轨迹规划与平滑（1 课时）

- **目标**：让机械臂动作"连贯、不抖、不撞限位"。
- **理论锚点**：笛卡尔路径采样 + 关节空间插值；平滑（如五次多项式 / 简单缓动）。
- **关键推导**：为什么直接对关节角线性插值，末端路径会"拐弯"？——引出"笛卡尔直线 vs 关节直线"的差异。
- **代码任务**：实现 `move_to(pos, R, steps)`：目标位姿 → IK → 关节插值 → 逐帧设置。
- **验收**：机械臂能平滑走出一条指定曲线，无明显抖动。

#### M13　综合任务开发（3 课时）

- **目标**：综合运用 FK/IK/轨迹完成一个真实小任务。
- **任务菜单（分层，团队任选）**：
  - **A｜轨迹绘图**：让末端沿空间中的直线 / 圆 / 正弦曲线运动并绘制轨迹。
  - **B｜抓取—搬运—放置**：从 A 点抓起物体放到 B 点（需同时处理位置与姿态）。
  - **C｜逆解鲁棒性挑战**：在关节限位与多解约束下，寻找"最合理"的一组解。
- **验收**：任务成功完成 + 代码可复现 + 能解释每一步的数学依据。

#### M14　展示、答辩与评价（2 课时）

- **目标**：表达成果，反思数学与工程的关系。
- **形式**：团队演示（含"预测—验证"日志回顾）+ 答辩（回答"为什么这样解""遇到什么坑"）。
- **验收**：见"评估方案"。

## 七、仿真平台接口契约（供平台准备时对齐）

> 以下为**建议的 Python API 契约**。用户准备仿真平台 / 代码 / 模型文件时，按此封装即可与课程无缝对接。
> 推荐引擎：**PyBullet**（纯 Python、易上手）或 **MuJoCo**（更精细）；也可用 THREE.js / CoppeliaSim 等。

```python
class ArmBot:
    """机械臂仿真接口（建议在平台上优先实现，两台机型共用）"""

    # —— 状态读写 ——
    def set_joints(self, q):            # q: 关节角列表（弧度）；UR5 长度 6，R1 长度 7
    def get_joints(self) -> list:       # 返回当前关节角
    def get_ee_pose(self) -> (pos, R):  # 返回末端位置(3,)与姿态矩阵(3,3) —— 真值
                                        # UR5 的末端参考系是 tool0，R1 是 Link7
    def reset(self):                    # 复位到初始姿态（UR5 零位末端约 (0.82, 0.19, -0.01) m）

    # —— 运动 ——
    def move_joints(self, q, steps=50): # 关节空间平滑运动
    def move_to(self, pos, R=None, steps=50):  # 触发平台IK移动到目标位姿（对照用）
    def draw_path(self, points, R=None):       # 让末端依次经过一串点位

    # —— 结构与辅助 ——
    def joint_limits(self) -> list:     # 各关节限位 [(lo,hi), ...]
    def reachable(self, pos) -> bool:   # 目标是否可达（可选实现）
    def wrist_report(self) -> dict:     # ★ 新增：检查"是不是球形手腕"（见 core/geometry.py）
    def show(self):                     # 渲染/刷新画面

# —— 两种模式（关键教学设计）——
# 真值模式：平台自带 fk/ik，用于对照与验收
# 学生模式：禁用平台内置 fk/ik，学生必须用自己的实现（防抄近路）
```

**配套脚手架建议**：为每个模块提供"填空式"代码骨架（TODO 标记 + 单元测试），学生只填写核心公式，其余由平台兜底。

## 九、风险预案与教学建议

| 风险 | 表现 | 预案 |
|---|---|---|
| **3D 抽象过载** | 学生卡在旋转矩阵 | 提前用 2D 类比 + 大量可视化；矩阵"逐列讲"；允许"先会用后深究" |

## 附录 A · 关键公式速查

**① 平面连杆末端（极坐标 → 直角坐标）**
```
x = L·cos θ
y = L·sin θ
```

**② 2R 平面正运动学（FK）**
```
x = L1·cos θ1 + L2·cos(θ1 + θ2)
y = L1·sin θ1 + L2·sin(θ1 + θ2)
```

**③ 2R 平面逆运动学（IK）——余弦定理**
```
cos θ2 = (x² + y² − L1² − L2²) / (2·L1·L2)
θ1 = atan2(y, x) − atan2(L2·sin θ2,  L1 + L2·cos θ2)
```
> 可达条件：`|L1 − L2| ≤ √(x²+y²) ≤ L1 + L2`

**④ 球坐标（空间位置）**
```
x = r·sin φ·cos θ
y = r·sin φ·sin θ
z = r·cos φ
```

**⑤ 基本旋转矩阵（绕 z 轴 α）**
```
Rz(α) = [ cos α  −sin α  0 ]
        [ sin α   cos α  0 ]
        [   0       0     1 ]
```
（Ry、Rx 结构同理，元素皆为 0 / ±1 / ±sin / ±cos）

**⑥ 变换链（三维正运动学）**
```
T_end = T1 · T2 · T3 · T4 · T5 · T6
```

**⑦ 核心函数 π 值提示**
```
atan2(y, x)  →  返回 (−π, π]，自动处理四个象限
```

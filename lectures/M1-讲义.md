# M1 讲义 · 机械臂怎么"知道"手在哪？

> **阶段一 · 启航｜2 课时（建议 2 × 45 分钟）**
> 关键词：正运动学（FK）· 逆运动学（IK）· 关节空间 · 笛卡尔空间 · 双机对照

---

## 一、本节要回答的问题

> **机械臂只有几个"会转的关节"。它怎么"知道"自己的手在空间的什么地方？
> 反过来，我想让它的手精准到达某个位置，它该怎么算每个关节要转多少度？**

这两个问题分别叫 **正运动学（Forward Kinematics, FK）** 和 **逆运动学（Inverse Kinematics, IK）**，
是机器人学的第一道门槛 —— 而它**恰好是一道纯粹的三角几何题**。这门课的全部内容，都围绕这句话展开。

### 学习目标

学完本节，你应当能够：

1. 用自己的话说清 **FK 与 IK 的区别**，并举出一个各自的应用场景；
2. 区分 **关节空间**（几个角度）与 **笛卡尔空间**（三个坐标）；
3. 说出 **UR5 与宇树 R1** 至少 3 条外观 / 规格上的差异；
4. 熟练使用仿真平台的两个基本操作：`set_joints(q)` 与 `get_ee_pose()`。

> 提示 —— 手的位置，其实是**一串角度经过三角函数计算的结果**。

### 3.2 两个空间

| | 关节空间（Joint Space） | 笛卡尔空间（Cartesian Space） |
|---|---|---|
| 用什么描述 | 每个关节的**角度**，如 `(θ₁, θ₂, …, θ₆)` | 末端的**位置坐标**，如 `(x, y, z)` |
| 谁在用 | 电机 / 伺服驱动器 | 我们人（"把手放到桌子上面"） |
| 换个说法 | "命令" | "目标" |

**FK 与 IK 就是这两个空间之间双向的翻译**：

```
   关节空间 (θ₁,…,θ₆)  ──────── 正运动学 FK ────────►  笛卡尔空间 (x, y, z)
                        ◄─────── 逆运动学 IK ────────
```

- **FK**：给定所有关节角 → 算出末端在哪（**一定有唯一答案**，好算）；
- **IK**：给定末端目标位置 → 反推每个关节角（**可能多解、可能无解**，难算）。

## 五、推：为什么这是一道三角题？

### 5.1 一根连杆的末端在哪？

想象一根长 `L` 的连杆，一端固定在原点，只能绕原点转动，与 x 轴夹角为 `θ`。

```
        y
        ▲
        │        ● 末端 (x, y)
        │      ╱ │
        │    ╱   │
      L │  ╱     │  L·sin θ
        │╱  θ    │
        └────────┴────────► x
           L·cos θ
```

**推导**：从单位圆出发 —— 单位圆上角度 `θ` 对应的点就是 `(cos θ, sin θ)`；
把半径从 `1` 放大到 `L`，两边同乘 `L`：

```
x = L · cos θ
y = L · sin θ
```

> ✍️ **请你把它写成代码**（M2 会正式实现这个函数 `polar_to_xy(L, theta)`）：
>
> ```python
> def polar_to_xy(L, theta):
>     x = ______________________
>     y = ______________________
>     return x, y
> ```

### 5.2 那六个关节呢？

一串连杆 = 一串三角函数的**叠加**：

```
x = L₁cos θ₁ + L₂cos(θ₁+θ₂) + L₃cos(θ₁+θ₂+θ₃) + …
y = L₁sin θ₁ + L₂sin(θ₁+θ₂) + L₃sin(θ₁+θ₂+θ₃) + …
```

**注意括号里那串角度是"累加"的** —— 这是本课程最重要的一句话，M3 会专门拆开讲。

```

### 任务 A：打印几组数据

```python
import numpy as np

model = load_model(UR5_URDF)      # 主力机型 UR5，6 自由度

## 八、小结与速查卡

```
① FK（正运动学）：关节角 ──► 末端位置      唯一解，好算
② IK（逆运动学）：末端位置 ──► 关节角      可能多解 / 无解，难算
③ 关节空间：用角度描述    笛卡尔空间：用坐标描述
④ 连杆末端：x = L·cos θ ,  y = L·sin θ      ← 全课的地基
⑤ 多连杆：角度要"累加" ——  第 i 段用 (θ₁+θ₂+…+θᵢ)
```

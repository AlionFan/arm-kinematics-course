## 四、推：从单位圆到连杆末端

### 4.1 单位圆：`sin` 和 `cos` 就是坐标

在**半径 = 1** 的圆上，从 x 轴正方向逆时针转过角度 `θ`，落点坐标为：

```
( cos θ , sin θ )
```

```
            y
            ▲
            │        ● (cos θ, sin θ)
            │      ╱│
            │    ╱  │  sin θ
            │  ╱ θ  │
            └────────┴────────► x
              cos θ
```

> ✍️ **填空**：由上图，横向坐标 = ______，纵向坐标 = ______。
> 这正是"sin/cos 是坐标"的含义 —— 它们**不是**先有三角形、再算边长，
> 而是**直接给出了一个点的位置**。

### 4.2 推广：半径从 1 变成 L

把单位圆整体**放大 L 倍**（两个坐标同乘 L）：

```
x = L · cos θ
y = L · sin θ
```

- 若 `L = 1`，就退回单位圆；
- `L` 决定"能伸多远"，`θ` 决定"伸向哪个方向"。
- 这就是**极坐标** `(L, θ)` 与**直角坐标** `(x, y)` 之间的翻译。

### 4.3 弧度制：数学里的"天然单位"

| | 角度制 | 弧度制 |
|---|---|---|
| 一整圈 | 360° | 2π |
| 平角 | 180° | π |
| 直角 | 90° | π/2 |

换算关系（务必背下来）：

```
弧度 = 角度 × π / 180
角度 = 弧度 × 180 / π
```

> 💡 **为什么用弧度？** 因为只有弧度制下，才有"弧长 = 半径 × 角度"这么干净的关系。
> Python 的 `math.sin` / `numpy.cos` 接收的**都是弧度**，所以写代码时要先换算：
> `np.radians(30)` → 0.5236。

### 4.4 反过来：已知坐标，求角度

已知 `(x, y)`，要求长度 `L` 和角度 `θ`：

- **长度**：勾股定理 → `L = √(x² + y²)`（Python 里用 `math.hypot(x, y)`）
- **角度**：**不能**直接用 `arctan(y/x)`！

**为什么？** 因为 `arctan` 只知道 `y/x` 的**比值**，分不清象限：

| 点 | `y/x` | `arctan` 给出 | 真实角度 |
|---|---|---|---|
| (1, 1) | 1 | 45° | 45° |
| (−1, −1) | 1 | 45° ❌ | 225°（或 −135°） |

正确做法是用 **`atan2(y, x)`** —— 它同时看 `x` 和 `y` 的**符号**，自动分辨四个象限，
返回值范围 `(−π, π]`：

```
θ = atan2(y, x)
```

> ✍️ **判断**：`atan2(1, −1)` 的结果是第几象限的角？大约是 ______ 度。
> （答案：第二象限，135°）

## 七、小结与速查卡

```
① 单位圆：角度 θ 对应的点 = (cos θ, sin θ)      ← "sin/cos 就是坐标"
② 连杆末端：x = L·cos θ ,  y = L·sin θ
③ 弧度换算：弧度 = 角度 × π / 180       （Python 里 np.radians / np.degrees）
④ 反向：L = hypot(x, y) ,  θ = atan2(y, x)      ← 必须用 atan2，不能用 arctan
⑤ 末端轨迹：单连杆匀速转一圈 → 画出一个「圆」    （圆的方程就是 sin/cos）
```

> **"圆的方程就是 sin / cos"** —— 记住这句话，它就是整门课的世界观起点。

## 一、本节要回答的问题

> **一根连杆的末端坐标我们算出来了（M2）。
> 那如果第二根连杆**装在第一根的末端上**呢？它的角度该怎么算？**

答案只有一句话，却是整门课最重要的一句话：

> **第二根连杆的角度要"累加" —— 它相对于第一根转了多少，它的"绝对方向"就是 `θ₁ + θ₂`。**

### 学习目标

1. 掌握 **1R → 2R → 3R** 平面臂的正运动学公式；
2. 理解**角度累加**（复合旋转）的几何含义，能解释"为什么要写 `θ₁+θ₂`"；
3. 能实现 `fk_2r(L1, L2, q1, q2)` 并推广到 3R；
4. 理解**可达空间**是圆环，并能说出内、外边界分别由什么决定。

## 三、探：第二个关节"转了多少"是相对谁？

### 3.1 动手前先想

```
          第二根连杆
              ╱
            ╱  θ₂ 是相对谁的角度？
          ╱
   ────●────────   第一根连杆（与 x 轴夹角 θ₁）
```

**两种可能**，你选哪个？

- (A) `θ₂` 是相对地面的（也就是相对 x 轴）；
- (B) `θ₂` 是**相对第一根连杆**的。

> ✍️ 我的判断：______
>
> 提示：真实的机械臂，"第二个关节的电机"是**装在第一根连杆的末端**上的 ——
> 它转的时候，整个"坐标系"已经跟着第一根连杆转过了。

**结论**：真实机械臂的关节角都是 **(B) 相对上一个连杆**的，这叫**相对角度**。

因此第二根连杆的**绝对方向**（相对 x 轴的角度）是：

```
θ₁ + θ₂
```

> 这就是后面"变换链"思想的雏形 —— 每个关节都只管"相对上一步转了多少"，
> 绝对姿态由前面所有角度**累积**得到。

## 四、推：从 1R 到 2R 到 3R

### 4.1 1R（复习 M2）

一段连杆的末端坐标，就是"长度 × 方向"的**向量**：

```
第一段：L₁ · (cos θ₁ , sin θ₁)
```

### 4.2 2R：两段向量相加

第一段的末端，就是第二段的**起点**。而第二段的方向角是 `θ₁ + θ₂`：

```
第二段：L₂ · (cos(θ₁+θ₂) , sin(θ₁+θ₂))
```

两段**首尾相接**，所以末端 = 两段向量相加：

```
x = L₁·cos θ₁ + L₂·cos(θ₁+θ₂)
y = L₁·sin θ₁ + L₂·sin(θ₁+θ₂)
```

```
        y
        ▲
        │             ● 末端 (x, y)
        │           ╱
        │         ╱  L₂ , 方向 = θ₁+θ₂
        │       ╱
        │     ●  (关节 2)
        │   ╱
        │ ╱   L₁ , 方向 = θ₁
        ●──────────────► x
      (0,0)
```

> ✍️ **请你写出 `fk_2r` 的两行核心代码**：
>
> ```python
> def fk_2r(L1, L2, q1, q2):
>     x = ______________________________________
>     y = ______________________________________
>     return x, y
> ```
>
> **提醒**：第二段的角度是 `q1 + q2`，不是 `q2`！

### 4.3 3R：再套一层

规律已经很明显了 —— **每多一段，就多"累加"一个角度**：

```
x = L₁cos θ₁ + L₂cos(θ₁+θ₂) + L₃cos(θ₁+θ₂+θ₃)
y = L₁sin θ₁ + L₂sin(θ₁+θ₂) + L₃sin(θ₁+θ₂+θ₃)
```

> ✍️ **推广到 3R**：把 `fk_2r` 改写成 `fk_3r(L1, L2, L3, q1, q2, q3)`，
> 你会怎么写？试着用**循环**把它写得更通用（提示：维护一个"累计角度"变量）：
>
> ```python
> def fk_nR(lengths, angles):
>     x = y = 0.0
>     acc = 0.0                      # 累计角度
>     for L, a in zip(lengths, angles):
>         acc += a                   # ← 累加！
>         x += L * np.cos(acc)
>         y += L * np.sin(acc)
>     return x, y
> ```

> 💡 **看出来了没有**：这个 `fk_nR` 已经能算**任意多段**的平面臂了。
> 将来把它从平面搬到三维、把 `cos/sin` 换成旋转矩阵 —— 就是 M8 的**变换链**。

### 4.4 可达空间：为什么是圆环？

设 `L₁ = 0.30, L₂ = 0.22`（本节实验用值）。

| 情形 | 两段方向关系 | 末端到原点距离 r |
|---|---|---|
| **伸得最远** | 两段同向（`θ₂ = 0°`） | `r_max = L₁ + L₂ = 0.52` |
| **缩得最短** | 两段反向（`θ₂ = 180°`） | `r_min = |L₁ − L₂| = 0.08` |

中间的所有距离都能取到，但由于"左右两侧都到得了"，
末端可达区域是一个 **圆环**：

```
        圆环：0.08 ≤ r ≤ 0.52  （单位：m）
```

## 七、小结与速查卡

```
① 1R：末端 = L₁·(cos θ₁, sin θ₁)
② 2R：x = L₁cos θ₁ + L₂cos(θ₁+θ₂)
      y = L₁sin θ₁ + L₂sin(θ₁+θ₂)          ← 注意第二段是 θ₁+θ₂
③ 3R：再累加一层 → L₃cos(θ₁+θ₂+θ₃) …
④ 角度累加 = 复合旋转 = 变换链的雏形
⑤ 可达空间：圆环  |L₁−L₂| ≤ r ≤ L₁+L₂
                 （L₁=0.30, L₂=0.22 时是 0.08 ~ 0.52 m）
```

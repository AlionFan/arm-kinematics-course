# STORY.md · 《机械臂运动学》前三讲 课堂授课 PPT

## ① 用户意图对齐

- **目标受众**：高中学生（零机器人基础、有基础 Python 与三角函数知识），课堂场景由教师投屏讲授，共 5 课时（M1 两课时 + M2 一课时 + M3 两课时）。
- **核心目标**：讲完后学生要相信并记住一句话——**"机械臂运动学就是一道三角函数题"**；能复述 FK/IK 与两个空间的区别，能写出 `x=L·cos θ, y=L·sin θ`，能解释第二根连杆的角度为什么是 `θ₁+θ₂`，并说出可达空间是一个由 `|L₁−L₂| ≤ r ≤ L₁+L₂` 决定的圆环。全部页面必须能直接投屏讲课。
- **PPT 长度**：21 页（含封面、目录、3 个章节扉页、结束页）。
- **视觉调性**：学术严谨 / 蓝白克制 / 证据驱动 / 板书感 / 无营销味。
- **内容边界**：
  - **必讲**：FK 与 IK 的定义与差异；关节空间 vs 笛卡尔空间；UR5 与宇树 R1 的对照（真实参数）；`x=L·cos θ, y=L·sin θ`；弧度制换算；`atan2` 与 `arctan` 的区别；`θ₁+θ₂` 角度累加；`fk_2r` 公式；可达圆环 0.08–0.52 m。
  - **不讲（明确留白）**：三维旋转矩阵与变换链的完整推导（M8）；逆运动学的解析解法（M4）；球形手腕的完整证明（M10，只埋伏笔）；动力学、轨迹规划、控制。
  - **禁碰**：杜撰公式或数据；把 UR5 说成球形手腕；把 `θ₂` 说成相对地面的角度；使用 AI 生成的假机械臂照片冒充真实设备。

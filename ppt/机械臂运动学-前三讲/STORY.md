## 1. v2 改版原则

v1（文字版）的问题是：每页塞满句子，学生读字、老师念字，图只是陪衬。v2 按三条原则重做：

| 原则 | 具体要求 | 落地方式 |
|---|---|---|
| **以图为主** | 每页一张大图，占内容区（88–640 px）面积 **≥ 60%** | 全部用 PPT 原生矢量形状绘制（圆、连线、箭头、弧、圆环、曲线），可在 PowerPoint/WPS 里继续编辑 |
| **公式与文字为辅** | 页面上只保留：标题 + 图上标注 + **至多一行公式** | 删掉所有解释性句子；正文段落字数压到每页 ≤ 40 字 |
| **解释进备注** | 讲稿、提问、易错点、时间分配全部写进**演讲者备注** | 21 页全部带备注，每页 **193–514 字**（约 2–4 分钟口播量） |

画布 1280 × 720 px（96 px = 1 in，EMU = px × 9525）；版心：页眉 0–76 / 内容区 88–640 / 页脚 656–700。

## 4. 备注（演讲者备注）写作规范

每条备注按固定顺序写，方便老师直接照读：

1. **开场定位**（1 句）——这页在全课里的作用
2. **读图顺序**（①②③）——手指着图，从左到右 / 从上到下
3. **关键结论**——学生必须记住的那一句
4. **易错点 / 提问设计**——现场怎么问、错误怎么演示
5. **数值印证**——可核对的真实数字或仓库文件路径

示例（P14 备注节选）：

> 问题：第二段连杆（L2）的转角 θ2 是从哪里量的？
> 答：θ2 是"相对转角"，从第一段连杆的延长线开始量，不是从 x 轴开始量。
> …可以让这个错误现场发生一次：用错公式跑一遍，让学生看到手臂歪掉的样子，印象会非常深。

## 6. 构建与自检

```bash
# 生成 PPT（21 页 + 备注）
python build_pptx.py            # → 机械臂运动学-前三讲.pptx

# 渲染预览（无 Office / LibreOffice 环境下的目检方案）
python preview.py 机械臂运动学-前三讲.pptx preview    # → preview/p01..p21.png + _sheet.png

# 版式自检：越界 / 文本溢出 / 压页脚 / 备注完整性
python check.py   机械臂运动学-前三讲.pptx

# 生成讲义配图
python figures.py               # → figures.pptx
python preview.py figures.pptx preview/fig
cp preview/fig/p01.png figures/fig_m1_joint_chain.png   # 依此类推
```

**为什么需要 `preview.py`**：本机没有 PowerPoint / WPS / LibreOffice 的可用渲染入口，
且 `tencent-pptx` 依赖的 `slidep` 引擎始终未落地。`preview.py` 用 Pillow 直接解析 PPTX 的
形状 XML（含 freeform 的 `a:custGeom` 路径、连接符的 flipH/flipV、donut 的 adj 值），
按 z 序重绘成位图，用于目检；`check.py` 则用真实字体度量估算文本高度，做溢出判定。
两者都是**校验工具**，不参与交付物生成。

自检结果：21 页 **0 越界 / 0 文本溢出 / 0 压页脚**，21 页全部带备注。
